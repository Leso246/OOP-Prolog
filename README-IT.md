## Introduzione

OOΠ è un progetto che estende Prolog con **funzionalità object oriented** come:

- Classi con ereditarietà multipla
- Campi e controllo dei tipi per valori numerici
- Metodi, incluso l'overloading
- Creazione e manipolazione delle istanze

Per la documentazione completa ed esempi dettagliati, guardare la [documentazione](docs/documentation-IT.md).
