## Introduction

OOΠ is a project that extends Prolog with **object oriented features** such as:

- Classes with multiple inheritance
- Fields and type checking for numeric values
- Methods, including overloading
- Creation and manipulation of instances

For full documentation and detailed examples, see the [documentation](docs/documentation.md).
